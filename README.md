# Multi-Tenant Enterprise Knowledge Search (RAG) Platform

A production-grade, multi-tenant enterprise search and question-answering platform built for MedInsure Labs. Features strict tenant isolation with PostgreSQL Row-Level Security (RLS), permission-aware hybrid search (vector + BM25) with cross-encoder reranking, and citation-backed streaming answers for B2B healthcare and insurance compliance.

**Status:** Sprint 1 in progress
